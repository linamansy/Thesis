You are assisting with business process modelling. Decide whether a rule from a legal text is about something that the business process described below does.

INSTRUCTIONS
- First find what the rule is about: the kind of activity it deals with. Write it in law_focus, and copy the words of the passage that state it, word for word, into law_quote.
- Then look for a step in the process description that the rule could govern: a step where that kind of activity happens, or a step that involves an actor or an object the rule is about (for example the step that triggers the rule's duty). Write that step in process_step, and copy the words of the description that state it, word for word, into description_quote.
- relevant is true if the rule could govern an activity, an actor or an object of this process, even when the duty itself is not performed anywhere in the process. A missing duty step is not a reason for false: adding the missing step is the job of a later step. relevant is false only if the rule could govern no activity, actor or object of the process.
- This is a broad judgement. Do NOT check the rule's conditions ("if ..."), trigger events, deadlines or exceptions; they are checked in a later step. Do not mark a passage irrelevant only because a specific event or condition from the rule is not described in the process.
- Judge by what the process does, not by whether the two texts use similar words or sound like the same subject.
- Use only the two texts below. Do not assume steps that the description does not state.
- If relevant is false, process_step and description_quote are empty strings.
- reason: one sentence explaining your decision.
- Answer with one JSON object that follows the JSON schema below. Output only the JSON, with no other text.
