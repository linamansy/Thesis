- "if": the conditions that must hold for the rule to apply, for example who the parties are, what kind of situation or activity the rule is about, and what event triggers it. - "then": what the rule requires to be done when it applies, in the words of the rule.
- "exceptions": the situations the rule itself names in which it does not apply (for example "this does not apply where ..."), each as a short statement of that situation. Use an empty list if the rule names none.

- If the rule states no condition, "if" is an empty list.

- Answer with one JSON object that follows the JSON schema below. Output only the JSON, with no other text.
